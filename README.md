# 小豬存錢樂園

給幼兒園大班（約 5–6 歲）的新台幣加法遊戲。只用 **1 元、5 元、10 元**，每一題和每一種玩法的金額都不會超過 **100 元**。

用平板橫向遊玩最剛好。可以點錢幣，也可以把錢幣拖進付款盤；爸爸媽媽可以一起用兩隻手指幫忙。

## 怎麼玩

1. **兔兔水果攤**：只用 1 元，一枚一枚數到剛剛好。
2. **熊熊冰淇淋車**：1 元和 5 元。五個 1 元會發光，可以合成一個 5 元。
3. **貓頭鷹玩具店**：加入 10 元，付款盤分成「十元區」和「一元／五元區」。
4. **動物大賣場**：一或兩樣商品，合起來不超過 100 元。
5. **自由玩**：沒有題目，可以拖、合成、用換錢機拆開，並聽到現在一共多少元。
6. **親子出題**：家長選 1～2 樣商品，輸入 1 到 100 元，換小朋友付錢。
7. **存錢筒**：付對的錢會掉進豬豬寶的肚子。存滿 100 元會慶祝，並解鎖星星披風。

星星可以幫豬豬寶換上蝴蝶結、草莓帽、眼鏡和小皇冠。設定裡可以切換卡通可愛版或寫實風格版硬幣，也可以關掉動畫或聲音。

說話預設是豬豬寶的台灣腔錄音（Microsoft 曉臻，zh-TW）。畫面上的價錢仍寫「元」，念出來是「塊」，例如「現在有十五塊喔！」。設定裡也可以改用這台裝置自己的台灣語音；沒有台灣語音時，不會改念成大陸或香港腔。

付太多的時候，錢幣會跳回原處，豬豬寶會說「太多囉，拿一個回來好不好？」。沒有倒數，也不會扣分。

## 放到 GitHub Pages

檔案就在這個資料夾的最外層（`index.html`、`manifest.json`、`sw.js`）。到倉庫的 Settings → Pages，Source 選 `main` 分支的根目錄即可。不需要建置。

用 iPad Safari 打開網址後，選「加入主畫面」，就可以全螢幕、離線玩。
